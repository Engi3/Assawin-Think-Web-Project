Level Sensors

Four different technologies can all answer the same question — "how full is this tank?" Fill the tank below and compare how each sensor type reports the level.

Knowledge Notes

  • Float switches in turbulent or wavy liquid can chatter falsely — many installations mount the float inside a stilling well (a perforated tube) to calm the liquid around it.
  • Ultrasonic level sensors have a dead zone/blanking distance near the sensor face where they cannot reliably measure — never mount them so the maximum expected level enters that zone.
  • Capacitive probes must be calibrated for the specific liquid's dielectric constant — the same probe reads differently in water vs. oil vs. a granular solid, so a probe re-used across tanks needs re-calibration.
  • Hydrostatic (pressure-based) level measurement needs the fluid's density/specific gravity to convert pressure correctly to height — the same pressure reading means a different level in water vs. a denser chemical solution.
  • High/low level switches are almost always wired directly into a pump interlock, not just an alarm — this unit's ladder example shows the classic set/reset auto-fill pattern.

High/Low Switch Wiring & an Auto-Fill Ladder

|--[ X0 ]-----------------------------------( SET Y0 )--|  // X0: low-level switch -> start fill pump (latch ON)
|--[ X1 ]-----------------------------------( RST Y0 )--|  // X1: high-level switch -> stop fill pump (latch OFF)
Applied example: a reservoir auto-fill system latches the fill pump ON (SET Y0) the moment the low-level switch X0 activates, and only unlatches it (RST Y0) once the high-level switch X1 is reached — the tank cycles between the two switch heights automatically, forever, with no operator intervention. The same latch pattern controls chemical dosing tanks and cooling tower makeup water.
