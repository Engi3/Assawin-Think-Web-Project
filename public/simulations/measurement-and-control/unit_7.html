PLC Programming: Reading & Scaling Industrial Control Modules

An analog module hands the PLC a raw ADC count. Scaling converts that count into a real engineering value; a ladder program then reads, scales, and acts on it. Try both steps below.

Engineering Value = ((Raw − 0) / (4000 − 0)) × (Max − Min) + Min — this is the exact formula behind a PLC's SCL/scaling instruction. Try Raw ADC = 1500, Min = −50, Max = 150 to match a typical 4–20mA temperature transmitter reading roughly 25°C.

Knowledge Notes

  • Every PLC brand has its own scaling instruction name for the same underlying formula: Mitsubishi FX uses SCL2, Siemens S7 splits it into NORM_X + SCALE_X, Omron uses SCL — the math in this unit's calculator is universal even though the instruction mnemonic isn't.
  • If Min > Max in the scaling setup, the relationship reverses (a higher raw count gives a lower engineering value) — useful for sensors wired to read "backwards," but easy to get wrong by accident.
  • Always double-check the module's channel addressing — a multi-channel analog module maps each physical input to a different D-register offset (e.g. channel 0 → D0, channel 1 → D1), and mixing them up reads the wrong sensor entirely.
  • Use the PLC's monitor/force mode to watch live raw and scaled values while testing — but always remove forced values before leaving the program, since a forced I/O point ignores real-world signals until cleared.
  • Simulate before you connect real actuators: verify a new scaling/logic rung against known reference inputs on the bench, before it's wired to a motor, valve, or heater that can cause real damage if the math is wrong.

A Complete Worked Example

|--[ Always ON ]----------------------( MOV D0 D10 )--|  // read raw ADC from analog ch0 into D10
|--[ Always ON ]------( SCL D10 K0 K4000 K-50 K1500 D20 )--|  // scale D10 (0-4000) to D20 (-50.0 to 150.0 x10)
|--[ D20 >= K1000 ]--------------------------------( Y5 )--|  // D20 >= 100.0 -> high-temperature alarm Y5
Applied example: this three-rung program reads a temperature transmitter's raw ADC value every scan (rung 1), scales it into a real, human-meaningful °C x10 value stored in D20 (rung 2, using the same formula as the calculator above), then compares that scaled value against a 100.0°C alarm threshold (rung 3). This exact read → scale → compare → act pattern is how every sensor from Units 2-6 gets wired into a real running control program.
