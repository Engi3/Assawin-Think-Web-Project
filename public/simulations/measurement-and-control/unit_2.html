บทที่ 2: การเขียนโปรแกรมลอจิกดิจิทัล (11 กรณีศึกษาที่สมบูรณ์)

Interactive Logic Engine: คลิกที่ Input (X) เพื่อจ่ายสัญญาณและเรียนรู้การสแกนโปรแกรม PLC จริง

คำสั่งพื้นฐานทางลอจิก (Basic Logic Instructions)

คำสั่ง (Instruction)สัญลักษณ์ (Symbol)การทำงานทางวิศวกรรม (Engineering Function)
LD (Load)| |หน้าสัมผัสปกติเปิด (NO) เริ่มต้น Rung ตรวจสอบว่ามีสัญญาณ Logic '1' หรือไม่
LDI (Load Inverse)|/|หน้าสัมผัสปกติปิด (NC) เริ่มต้น Rung ตรวจสอบว่าไม่มีสัญญาณ Logic '0' หรือไม่
ANDอนุกรม | |เชื่อมต่อแบบอนุกรม (Series) ลอจิก AND (กระแสจะไหลเมื่อเงื่อนไขเป็นจริงทั้งหมด)
ORขนาน | |เชื่อมต่อแบบขนาน (Parallel) ลอจิก OR (กระแสจะไหลเมื่อเงื่อนไขใดเงื่อนไขหนึ่งเป็นจริง)
OUT( )ส่งผลลัพธ์ไปกระตุ้น Coil ของ Output (Y) หรือ Internal Relay (M)
SET[SET]สั่ง Output ทำงานค้าง (Latching Instruction) แบบฮาร์ดแวร์
RST (Reset)[RST]ยกเลิกการทำงานค้าง (Unlatch) ของคำสั่ง SET หรือ Timer/Counter
LDP (Load Pulse)|P|Edge Trigger ขอบขาขึ้น ทำงานเพียง 1 Scan Cycle (ส่งสัญญาณพัลส์สั้นๆ เมื่อ Input เปลี่ยนจาก 0 -> 1)
LDF (Load Falling)|F|Edge Trigger ขอบขาลง ทำงานเพียง 1 Scan Cycle (ส่งสัญญาณพัลส์สั้นๆ เมื่อ Input เปลี่ยนจาก 1 -> 0)
