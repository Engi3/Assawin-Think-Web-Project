ข้อที่ 1: วงจรควบคุมพื้นฐาน (Direct Control)

โจทย์: เมื่อกดสวิตช์ X0 หลอดไฟ Y0 จะติด และเมื่อปล่อย X0 หลอดไฟจะดับ แต่ถ้ากดสวิตช์ X1 ค้างไว้ หลอดไฟ Y0 จะไม่ติดแม้จะกด X0 ก็ตาม

  • X0 (NO): ทำหน้าที่เป็นสวิตช์เปิด (Start)
  • X1 (NC): ทำหน้าที่เป็นสวิตช์ตัดวงจร (Stop/Block)
  • Y0 (Coil): แทนหลอดไฟ

ข้อที่ 2: วงจรล็อกตัวเอง (Self-Holding / Latching Circuit)

โจทย์: กดสวิตช์ X0 แล้วปล่อย มอเตอร์ Y0 จะทำงานค้างไว้ (ล็อกสถานะตัวเอง) หากต้องการให้มอเตอร์หยุดทำงาน ต้องกดสวิตช์ X1

นี่คือวงจรที่สำคัญที่สุดในงานอุตสาหกรรม! โดยการนำ Contact NO ของ Y0 มาต่อขนานกับ X0 เมื่อ Y0 ทำงาน ไฟจะไหลผ่านหน้าสัมผัสของตัวมันเองแทน X0 ทำให้ทำงานค้างได้

ข้อที่ 3: วงจร Interlock (ป้องกันการทำงานซ้อนทับ)

โจทย์: ระบบมอเตอร์หมุนซ้าย-ขวา
- กด X0 ให้มอเตอร์หมุนซ้าย (Y0 ทำงาน)
- กด X1 ให้มอเตอร์หมุนขวา (Y1 ทำงาน)
เงื่อนไขความปลอดภัย: ห้าม Y0 และ Y1 ทำงานพร้อมกันเด็ดขาด (ป้องกันการช็อต) ดังนั้นถ้า Y0 ทำงานอยู่ กด X1 จะไม่มีผล จนกว่าจะกด Stop (X2) ก่อน

ข้อที่ 4: การใช้งาน Timer (หน่วงเวลา)

โจทย์: เมื่อกดสวิตช์ X0 ค้างไว้ 3 วินาที หลอดไฟ Y0 ถึงจะทำงาน หากปล่อย X0 ก่อน 3 วินาที Timer จะถูกรีเซ็ต

T0 K30: T ย่อมาจาก Timer, ส่วน K คือค่าคงที่ (Constant). ใน PLC FX Series Timer 100ms หากตั้งค่า K30 = 30 * 100ms = 3000ms (3 วินาที)

ข้อที่ 5: การใช้งาน Counter (ตัวนับจำนวน)

โจทย์: เมื่อกดสวิตช์ X0 ครบ 5 ครั้ง (นับสินค้า) หลอดไฟ Y0 จะสว่างขึ้น หากต้องการเริ่มนับใหม่ให้กดปุ่ม X1 เพื่อรีเซ็ต

C0 K5: C ย่อมาจาก Counter จะนับขึ้น 1 ค่าทุกครั้งที่สัญญาณ X0 เปลี่ยนจากดับเป็นติด (Rising Edge) เมื่อนับถึง 5 หน้าสัมผัส C0 จะทำงาน

[ RST C0 ]: คำสั่ง Reset ใช้ล้างค่าใน Counter กลับเป็น 0

ข้อที่ 6: คำสั่งล็อกและปลดล็อกสถานะ (SET / RST)

โจทย์: ทำงานคล้ายคลึงกับ Self-Holding แต่เขียนโปรแกรมได้สั้นกว่า เมื่อกด X0 คำสั่ง SET จะบังคับให้ Y0 ทำงานค้างไว้ และเมื่อกด X1 คำสั่ง RST (Reset) จะสั่งให้ Y0 หยุดทำงาน

[ SET Y0 ]: บังคับให้ Output เป็นสถานะ ON ค้างไว้ แม้สัญญาณ Input จะหายไปแล้ว

[ RST Y0 ]: บังคับให้ Output กลับไปเป็นสถานะ OFF

ข้อที่ 7: สวิตช์ปุ่มเดียวสลับสถานะ (Alternate - ALT)

โจทย์: ใช้ปุ่ม X0 เพียงปุ่มเดียว กดครั้งแรกหลอดไฟ Y0 ติด กดปุ่ม X0 เดิมอีกครั้ง หลอดไฟ Y0 ดับ สลับกันไปมา

X0 (|↑|): สัญลักษณ์ลูกศรขึ้น คือการจับ Rising Edge (Pulse) จะปล่อยสัญญาณชั่วขณะ 1 สแกนไซเคิลเมื่อถูกกด

[ ALT Y0 ]: คำสั่ง Alternate (เฉพาะในตระกูล FX) สลับสถานะของ Output ทุกครั้งที่ได้รับสัญญาณ Pulse

ข้อที่ 8: วงจรไฟกะพริบ (Flicker Circuit)

โจทย์: เมื่อเปิดสวิตช์ X0 ค้างไว้ หลอดไฟ Y0 จะกะพริบ ติด 1 วินาที และ ดับ 1 วินาที สลับกันไปเรื่อยๆ จนกว่าจะปิด X0

ใช้ Timer 2 ตัวทำงานร่วมกัน T0 นับเวลาดับ (1s) เมื่อครบจะกระตุ้น T1 ให้นับเวลาติด (1s) และตัดวงจรตัวเองเพื่อรีเซ็ตวัฏจักรใหม่

ข้อที่ 9: การเริ่มทำงานเรียงลำดับ (Sequential Start)

โจทย์: เมื่อกด X0 มอเตอร์ Y0 จะทำงานทันที หลังจากนั้น 3 วินาที มอเตอร์ Y1 จะทำงานตามมาอัตโนมัติ หากกด X1 ระบบทั้งหมดจะหยุดทำงาน

เป็นการผสมผสานระหว่างวงจร Self-Holding และ Timer เข้าด้วยกัน ซึ่งพบเจอได้บ่อยในการสตาร์ทมอเตอร์ขนาดใหญ่หรือสายพานลำเลียง

ข้อที่ 10: การหยุดการทำงานอัตโนมัติ (Limit Switch)

โจทย์: ระบบเลื่อนของ กด X0 ของจะเลื่อนไปทางซ้าย (Y0) เมื่อชนเซ็นเซอร์ X2 จะหยุดเลื่อน และเมื่อกด X1 จะเลื่อนไปทางขวา (Y1) เมื่อชน X3 จะหยุด (ระบบมี Interlock ภายในตัวป้องกันการกดพร้อมกัน)
